Problem Statement

Project Overview

Predicting student academic performance early enables timely intervention — helping educators identify at-risk learners, allocate support resources, and personalize learning pathways. This project builds a complete supervised-regression pipeline that forecasts a student's final exam score (0–100) from a rich set of academic, behavioral, and demographic indicators.

The pipeline spans the full ML lifecycle: data generation, preprocessing, exploratory data analysis, feature engineering, multi-model training, evaluation, and deployment through an interactive web predictor that runs the trained model entirely in your browser.

The full supervised-ML lifecycle — from synthetic data generation through client-side deployment. Hover any phase.

01

Data Generation & Loading

Synthetic dataset of 1,200+ students generated with realistic distributions, injected missing values (40 in sleep_hours, 25 in internal_assessment_2) and 15 duplicates to make preprocessing meaningful.

02

Preprocessing

Duplicate removal, median imputation for missing numeric values, and IQR-based outlier capping (1.5×IQR) on key columns: attendance, study hours, assignment & assessment scores, final exam score.

03

Exploratory Data Analysis

Univariate (score distribution), bivariate (study hours vs score, parental support vs score), and multivariate (correlation heatmap) analysis to uncover the strongest predictors.

04

Feature Engineering

Two domain-driven features: avg_internal_score (mean of two assessments) and engagement_index (attendance × study hours) — the latter became the model's top feature.

05

Model Building

Three regression models trained & compared: Linear Regression (with StandardScaler), Random Forest (300 trees, depth 8), and Gradient Boosting (300 trees, lr 0.05, depth 3).

06

Evaluation

Metrics: MAE, MSE, RMSE, and R² Score on a held-out 20% test set. Gradient Boosting achieved the best R² of 0.7084 — selected as the deployment model.

07

Deployment

The trained model is exported (300 trees + init + learning rate) and the inference is reimplemented in TypeScript, so predictions run entirely client-side — no server round-trips.

Domain Knowledge

Feature Engineering

avg_internal_score

The mean of internal_assessment_1 and internal_assessment_2. Condenses two correlated mid-semester signals into a single, more stable academic-progress indicator.

avg_internal_score = (IA1 + IA2) / 2
3rd most important feature (15.7% importance)
engagement_index

The product of attendance (as a fraction) and weekly study hours. Captures the intuition that consistent and diligent students outperform those who only attend or only study.

engagement_index = (attendance / 100) × study_hours_per_week
#1 most important feature (36.9% importance)
Outcomes

Results & Conclusion

Key Findings

  • Gradient Boosting was the best model with R² = 70.84% and MAE = 5.006 points.
  • The engineered engagement_index (attendance × study hours) was the single most predictive feature (36.9% importance) — confirming that consistent, diligent study habits matter most.
  • Assignment scores and average internal assessment scores were the next strongest predictors.
  • Students without internet access and those with a part-time job showed lower predicted scores, flagging equity-of-access considerations.
  • Ensemble methods (GBM, RF) outperformed linear regression, indicating non-linear feature interactions.

Limitations & Future Work

  • Dataset is synthetic; swapping in a real-world dataset (e.g. from Kaggle) would validate generalization and check for overfitting.
  • Hyperparameter tuning via GridSearchCV could further improve R².
  • Cross-validation (k-fold) would give more robust error estimates.
  • The SHAP summary is a marginal-contribution approximation; a true TreeSHAP would give exact Shapley values.

Ethical Considerations
  • Synthetic data: predictions reflect the data-generation assumptions, not real student outcomes. Do not use for individual student evaluation.
  • Socioeconomic proxies: features like family income, internet access, and parental support can encode structural inequities. Avoid using predictions to justify resource denial.
  • Self-fulfilling labels: low predictions could lower expectations. Pair predictions with human judgment and supportive intervention, never punishment.
  • Privacy: if deployed on real students, secure consent, data minimization, and FERPA-equivalent protections are required.

ML Glossary
Reference for every ML term used in this project. Search or filter by category.
R² Score
Coefficient of Determination
Metric

The proportion of variance in the target explained by the model. 0 = no better than predicting the mean; 1 = perfect. Our model explains ~71% of score variance.

MAE
Mean Absolute Error
Metric

Average absolute difference between predicted and actual scores, in points. Lower is better. MAE=5 means predictions are off by ~5 points on average.

RMSE
Root Mean Squared Error
Metric

Square root of the average squared error. Penalizes large errors more than MAE. RMSE ≥ MAE always.

MSE
Mean Squared Error
Metric

Average of squared errors. Sensitive to outliers due to the squaring.

Gradient Boosting
Sequential tree ensemble
Method

An ensemble of 300 sequential decision trees, each correcting the residual errors of the previous. Learning rate 0.05, max depth 3.

PDP
Partial Dependence Plot
Method

Shows the average effect of one feature on the prediction, sweeping it across its range while holding all other features at their mean. Reveals the global trend.

ICE
Individual Conditional Expectation
Method

Like a PDP but for individual instances — one line per real student. Diverging lines reveal feature interactions the PDP average hides.

SHAP
SHapley Additive exPlanations
Method

A game-theoretic method attributing each prediction to feature contributions. The global summary (beeswarm) shows how each feature pushes predictions up/down across all students.

Bootstrap CI
Bootstrap Confidence Interval
Method

An uncertainty band built by refitting the model on many resampled (with replacement) training sets. The 5th–95th percentile range = 90% CI.

IQR
Interquartile Range
Method

Q3 − Q1, the spread of the middle 50% of data. Outliers are capped at Q1 − 1.5×IQR and Q3 + 1.5×IQR to limit extreme values.

Engagement Index
Engineered feature
Feature

attendance × study_hours_per_week (attendance as a fraction). The model's #1 feature (37% importance) — captures that consistent AND diligent students outperform.

avg_internal_score
Engineered feature
Feature

Mean of internal_assessment_1 and internal_assessment_2. Condenses two correlated mid-semester signals into a single, more stable indicator.

Residual
actual − predicted
Concept

Positive = the model under-predicted; negative = over-predicted. A well-calibrated model has residuals centered at 0.

Overfitting
Memorizing vs generalizing
Concept

When a model memorizes training data instead of learning generalizable patterns. Detected when train performance ≫ test performance.

Feature Importance
Relative contribution
Concept

How much each feature contributes to the model's predictions, averaged across all trees. Sums to 1 (or 100%).

Label Encoding
Categorical → numeric
Method

Converts text categories (e.g. 'Low'/'Medium'/'High') to integers (0/1/2) so the model can use them. Order is alphabetical, not semantic.
